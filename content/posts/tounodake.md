天気予報では曇り＆降水確率30%だったのに…。

08:40 ヤビツ峠バス停 〜 09:05 登山口 〜 10:15 三ノ塔 〜 12: 20 塔ノ岳（ランチ〜 13:10）〜 15:05 大倉バス停

全長：約14.5km

標高差：約1200m

<script src="http://latlonglab.yahoo.co.jp/route/paste?id=225f6d55a71eb309939adb3eb1821453&amp;width=480&amp;height=480" type="text/javascript"></script>

今日は久しぶりに複数名でのハイクで、<!--more-->丹沢の塔ノ岳の<a href="http://www.kankou-hadano.org/hadano_mountain/mountain_o2js.html" target="_blank">表尾根縦走</a>に行ってきました。６時台の小田急でいざ秦野へ。秦野のバス停は結構な人で臨時便に乗ることに。臨時便は15〜20分遅れで出発するので、もし早めに登り始めたい人は立ってでも定刻出発のバスに乗ることをオススメします。

8:20ぐらいにヤビツ峠に到着。お腹の調子が悪く、急いでバス停脇のトイレ（結構ちゃんとしたトイレ）に駆け込む。8:40分ぐらいにバス停から右のほうへ車道を下って登山口を目指します。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0152.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0152-300x225.jpg" title="登山口まで車道歩き" width="300" height="225" class="alignnone size-medium wp-image-2078" /></a>

20分ほど歩いたら富士見山荘に到着。朝９時でも営業中。ここで左折。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0153.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0153-300x225.jpg" title="富士見山荘" width="300" height="225" class="alignnone size-medium wp-image-2079" /></a>

この道を上がったところに登山道があります。この写真すぐ左に大きなトイレがあります。（トイレがやたらと気になった一日でした。）立て看板がありましたが、厳冬期、雪の具合どうなんでしょ。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0154.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0154-300x225.jpg" title="登山道へつながる道" width="300" height="225" class="alignnone size-medium wp-image-2080" /></a>

9:05に登山口到着。お山初心者のF君にトレッキングポールを１本貸してあげることに。（終始感動してました。）

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0155.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0155-300x225.jpg" title="登山口" width="300" height="225" class="alignnone size-medium wp-image-2081" /></a>

登り始めて30分ぐらいしたら景色のいい場所に到着。写真には写っていませんが、江ノ島も見えました。気温もそこまで高くなく、ヒンヤリした風がすごく心地の良かったです。（この辺は）

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0157.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0157-300x225.jpg" title="景色のいい場所" width="300" height="225" class="alignnone size-medium wp-image-2082" /></a>

この先の三ノ塔までは歩きやすい整備された道です。途中、笹のトンネルをくぐります。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0158.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0158-300x225.jpg" title="トンネル" width="300" height="225" class="alignnone size-medium wp-image-2083" /></a>

三ノ塔の小屋まではまだまだです。というか、まだ二ノ塔にも到着してない…。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0159.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0159-300x225.jpg" title="三ノ塔の小屋" width="300" height="225" class="alignnone size-medium wp-image-2084" /></a>

9:50二ノ塔に到着。三ノ塔まで500mです。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0160.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0160-300x225.jpg" title="二ノ塔" width="300" height="225" class="alignnone size-medium wp-image-2085" /></a>

10:15三ノ塔到着。ガスってます。その上、雨がポツポツ。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0162.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0162-300x225.jpg" title="三ノ塔" width="300" height="225" class="alignnone size-medium wp-image-2086" /></a>

ここから見える景色は絶景…なはず。晴れた日に来たかった〜。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0163.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0163-300x225.jpg" title="絶景なはず" width="300" height="225" class="alignnone size-medium wp-image-2087" /></a>

三ノ塔からは少し道が山っぽくなってきます。３カ所ぐらいかな？塔ノ岳まで鎖がかかっているとこがありました。（全然大したことないですが。）

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0165.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0165-300x225.jpg" title="三ノ塔からの下り" width="300" height="225" class="alignnone size-medium wp-image-2088" /></a>

たぶん行者岳付近だと思います。三ノ塔から烏尾山（写真撮らず）を越えてきました。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG01671.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG01671-300x225.jpg" title="山越え〜" width="300" height="225" class="alignnone size-medium wp-image-2101" /></a>

行者岳付近の鎖場で渋滞。足場はしっかりしているし、高さもないので、危険度は低いです。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0169.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0169-300x225.jpg" title="鎖場渋滞" width="300" height="225" class="alignnone size-medium wp-image-2090" /></a>

下から見た図。登る方が面倒かも。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0171.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0171-300x225.jpg" title="鎖場　下から見た図" width="300" height="225" class="alignnone size-medium wp-image-2091" /></a>

ここから新大日、塔ノ岳までいくつか瘦せ尾根を歩いていきます。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0170.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0170-300x225.jpg" title="痩せ尾根" width="300" height="225" class="alignnone size-medium wp-image-2092" /></a>

しっかりと補強されています。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0172.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0172-300x225.jpg" title="補強されている尾根" width="300" height="225" class="alignnone size-medium wp-image-2093" /></a>

新大日を通過し、ようやく塔ノ岳に到着。ガス、強風、雨、最悪のコンディション。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0173.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0173-300x225.jpg" title="塔ノ岳" width="300" height="225" class="alignnone size-medium wp-image-2094" /></a>

外でサクッとランチをして、ソソクサと下山する予定だったのですが、同行者の一人がレインウェアを忘れ凍え出したので尊仏山荘にて休憩。サンドイッチｘ２、薄皮チョコクリームパンｘ３を食べたのにも関わらず、カップヌードル（お湯付きで350円）をオーダー。しっかり暖まって、大倉尾根で下山開始。

塔ノ岳山頂直下すぐには鹿が２匹いました。人に慣れているんでしょうね。ほんの1mも離れていないのに、逃げもせずおしっこシャーっ。動物園か、ここは…。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0174.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/06/RIMG0174-300x225.jpg" title="ぺろぺろ" width="300" height="225" class="alignnone size-medium wp-image-2095" /></a>

下山はひたすら大倉尾根を下るのみ。通称バカ尾根と呼ばれる訳がよくわかるくらい、ずーっと下りが続きます。おかげで膝が痛くなりました。いや〜、この尾根は絶対登りたくない。

大倉尾根を下り終え、車道に出て少しするとバス停に到着。塔ノ岳から２時間ほどかかりました。ビジターセンターが併設されており、ここ、すごく設備がいいです。きれいなトイレ（今日はそればっかり…）、休憩所、自販機、食堂、靴の泥落とし場、至れり尽くせりです。顔を洗い、靴を洗い、コーラで喉を潤して、ちょっとするとバスが丁度いい具合にやってきました。（１時間に２本ぐらいあります。）バスに乗って渋沢駅に行き小田急に乗り帰宅したのが5時ちょっと過ぎでした。

３ヶ月ぶりのお山は、ガスってたり、雨が降ったりでしたが、ちょうどいい疲労感でなかなか満足感のあるものになりました。おしまい。

[メモ]

気合いを入れて虫除け対策用グッズを持っていきましたが、あまり虫はおらず。蚊は飛んでいましたが、大量ではなかったです。蚊取り線香もヘッドネットも使用せず。DEETとアームカバーで事足りました。
