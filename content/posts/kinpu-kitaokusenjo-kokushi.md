お家事情でテント泊禁止令が10月まで出ているので、梅雨明け？の3連休の中日に奥秩父の金峰山、金峰山・北奥千丈岳・国師ヶ岳に行ってきました。天気は最高、眺めも最高、虫さん達の数も今までで最高でした。

07:33 大弛峠登山口  〜 09:05 金峰山 〜 10:27 大弛峠登山口 〜 11: 04 北奥千丈岳 〜 11:14 国師ヶ岳 〜 11:38 大弛峠登山口

全長：約12km

標高差：約200m

朝の3時起き、自宅4時発で中央道を経て勝沼へ。中央道はすごく<!--more-->空いてました。そして勝沼〜塩山〜国道140号〜国道206号〜焼山峠〜川上牧丘林道（山梨県側）へ。という予定だったというか、カーナビもそう設定したはずなのに…勝沼で降りたのにも関わらず国道610号〜国道106号〜国道68号で峰越林道（長野県側）に連れてこられました。おぃっ！！！おかしいなと気がついたのは韮崎という標識が出てから。。。もういいやってことで、そのままカーナビに身を任せることに。

韮崎すぎまでずっと曇りでしかも雨まで降り出す始末。やべー、今日雨具持ってきてないよーと思っていたら、途中でどんどん雲が晴れドピーカンに。おぉ山の神よ！（これでちょっとルートロスの気分も晴れました。）

さて峰越林道ですが、ガイドブックによると悪路です。最初舗装されていますが。（といってもボコボコです）↓

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0177.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0177-300x225.jpg" title="峰越林道" width="300" height="225" class="alignnone size-medium wp-image-2138" /></a>

ちょっとするとダートに変わります。結構ガレている＆道に対して垂直できた溝が所々あるので、オフローディングが楽しめます。車高の低い車は厳しいかも。うちの車はクロカン用に改造しているのでノープロブレモ。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0179.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0179-300x225.jpg" title="峰越林道　ダート" width="300" height="225" class="alignnone size-medium wp-image-2140" /></a>

林道を走り始めて一台も出くわすことなく7:21到着。ここ、大弛峠駐車場（登山口）から300mほど下ったところなんですが、こんなにも車が…。ほとんどの車が全然汚れてないことから、きっと山梨県側の川上牧丘林道から登ってきたんでしょうね。おにぎりを2個を頬張り、急いで準備して登山口へ向かいます。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0180.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0180-300x225.jpg" title="駐車場より300m離れた場所に停車" width="300" height="225" class="alignnone size-medium wp-image-2141" /></a>

大弛峠の登山口。この大弛峠、道を挟んで２つ登山口があります。一つは金峰山方面、もう一つは国師、甲武信岳方面。今日はまず最初に金峰山へ。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0181.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0181-300x225.jpg" title="大弛峠　登山口" width="300" height="225" class="alignnone size-medium wp-image-2142" /></a>

金峰山まで途中岩場も少しありますが、歩きやすい道が続きます。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0182.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0182-300x225.jpg" title="登り始め" width="300" height="225" class="alignnone size-medium wp-image-2143" /></a>

しばらくすると富士山絶景ポイントに到着。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0183.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0183-300x225.jpg" title="富士山" width="300" height="225" class="alignnone size-medium wp-image-2144" /></a>

そしてまたそこから10分ほどすると朝日岳の肩に到着。絶景ポイントです。

ここから五丈岩までひと下りなんですが、先を急ぐので下るのはやめ。行っておけばよかったと、あとでちょっと後悔。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0202.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0202-300x225.jpg" title="五丈岩" width="300" height="225" class="alignnone size-medium wp-image-2155" /></a>

今回のシューズはモントレイルのサビノトレイル Mid。Lowaのレネゲードがとうとうお亡くなりになったので、<a href="http://outdoorlabo.a-ce.com/2010/06/26/tounodake/" target="_blank" rel="noopener">塔ノ岳</a>の前に購入。詳しいレポは後日しますが、軽いです。トラクションも悪くないかな。スーパーフィート入れたら、もうワンサイズ大きくてもよかったかもといったフィット感になってしまいました。（涙）ソックスを薄いのにするか、デフォのインソールを使うかですね。スパッツ忘れて、帰宅後靴の中まで洗う始末に。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0204.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0204-300x225.jpg" title="サビノトレイル Mid GTX" width="300" height="225" class="alignnone size-medium wp-image-2156" /></a>

金峰山から大弛峠まで来た道を戻ります。途中、虫の一番少なかった金峰山のケルンにておにぎり補給。往復3時間ほどで大弛峠に戻ってきました。次は北奥千丈岳、国師ヶ岳へ向かいます。こちら側の登山口を登ったすぐのところに大弛小屋があります。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0205.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0205-300x225.jpg" title="大弛峠　登山口" width="300" height="225" class="alignnone size-medium wp-image-2157" /></a>

北奥千丈岳と国師ヶ岳分岐の三繋平までず〜っと木の階段が続きます。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0206.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0206-300x225.jpg" title="木の階段" width="300" height="225" class="alignnone size-medium wp-image-2158" /></a>

三繋平にて北奥千丈岳と国師岳に分岐します。とりあえず先に北奥千丈岳へ行ってみることに。

山梨百名山なんですと。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0215.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0215-300x225.jpg" title="山梨百名山" width="300" height="225" class="alignnone size-medium wp-image-2165" /></a>

全行4時間の山歩きを終え、本日3回目の大弛峠に到着。

<a href="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0216.jpg"><img src="http://outdoorlabo.a-ce.com/wp-content/uploads/2010/07/RIMG0216-300x225.jpg" title="大弛峠" width="300" height="225" class="alignnone size-medium wp-image-2166" /></a>

標高差があまりないので、心地よいアップダウンでした。休憩らしい休憩も金峰山のケルンで3分ほどのみ。あとはずっと写真を撮るのに立ち止まるぐらい。まぁ、鬱陶しい虫のせいってのもあるんですが…。

大弛峠〜金峰山〜大弛峠はお気軽ハイキング。大弛峠〜北奥千丈岳＆国師ヶ岳〜大弛峠はスーパーお気軽ハイキングという感じですかね。テント担いで大弛峠〜甲武信岳もおもしろいかもです。

帰りは、懲りずに峰崎林道のダート道を下り、清里方面を経て、でっかい八ヶ岳を右側に臨みながら長坂ICから中央道に乗りました。いや〜、最高に気持ちの良いドライブになりました。オススメ。
